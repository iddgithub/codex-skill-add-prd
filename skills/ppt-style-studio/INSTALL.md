# 安装与使用

这是可移植的 `ppt-style-studio` 技能文件夹。公开包只含工作流与视觉规则，不含用户项目源文件和历史PPT参考资产。

## Codex

把整个 `skills/ppt-style-studio` 文件夹复制到 `~/.codex/skills/ppt-style-studio`，重启或刷新技能列表。然后使用 `$ppt-style-studio`，或直接说“按资料做PPT”。

## Claude Code 与其他支持 SKILL.md 的模型

将整个文件夹放入对应客户端的技能目录，例如 Claude Code 的 `.claude/skills/ppt-style-studio`。若客户端不支持自动发现技能，把 `SKILL.md` 作为工作指令并保持 `references/` 同目录可访问。

## 使用流程

1. 提供主题、想法或可选文档。技能先按业务和受众设计每页观点、机制、证据与完整上屏文案，汇总对应大纲。
2. 确认内容后，查看A比赛铂银影像风格与B/C业务定制风格各三个真实页面。
3. 选定风格后制作全稿。若你有要模仿的比赛PPT，请同任务提供，视觉更准确。

不同模型的图像、PPTX和文件工具不同，成品能力取决于实际环境。技能要求内容、证据和图文关系一致，但不绑定某一家的工具接口。
