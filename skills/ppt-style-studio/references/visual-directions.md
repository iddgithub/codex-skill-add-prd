# 三种视觉方向

每次选样都使用同一组已确认实际页面。每组包含封面、核心方案/业务页、较密集的流程/架构/数据页，三种方向合计九张。先读取 [整套一致性规范](consistency.md) 与 [内容对应规则](content-mapping.md)。

## A 固定以比赛整套风格为默认

默认A采用铂银影像比赛风格。用户提供完整比赛PPT或PDF时，以封面、章节、业务流程和技术架构等不同页型确定视觉；未提供时依据本节文字规范创作并说明是近似演绎。
- 银白与淡冰蓝背景，深海军蓝正文，钴蓝强调。起始参考色为 #F1F5FC、#DFE9F7、#071D43、#0862E8。
- 封面左侧大标题，右侧单一行业主视觉。
- 内容页左上章节标签、大标题、短副标题及蓝色弧线，统一标题区域与边距。
- 浅银、冰蓝和半透明玻璃材质贯穿设备、图标、流程与架构，采用一致的冷色柔和光照。
- 章节页延续同底色与标题语言，保留有意义的留白。

将主视觉、角色和业务内容替换为当前任务。旧赛事标识、机构、人物、产品、数据和MRI设备不自动沿用。用户明确要求改变A时按其要求调整。

## B、C 按当前业务定位重新设计

B、C每个项目重新推导，不固定使用旧版的“冷灰商务”和“钛金深蓝”。这两种旧方案可以在确实适合本次业务时成为候选，但应说明当前业务依据。

从资料提炼以下设计输入：
- 业务是什么，核心服务、产品和价值是什么。
- 给谁看，受众关心哪些问题。
- 用于合作洽谈、学术汇报、投资路演、政府评审、产品发布或培训中的哪种场景。
- 希望促成什么决定。
- 哪些页面信息较密集，哪些证据和品牌要求必须保留。

据此形成两个不同但都适配业务的方向，各给一个具体名称和一句设计理由，并确定字体、配色、构图、材质与图标语言。差异应体现信息组织和业务气质，避免只给同一模板换底色。

例如，面向医疗学术组织的合作项目，可以探索强调严谨与专家协同的学术表达，以及强调跨院运营与患者服务的协作网络表达。政企、教育、消费或其他业务需要按其自身定位设计。这些是推导示例，不是固定主题、名称或颜色。

## 选样对比与一致性

三组使用同样的正式页ID、标题、文字信息、数值与关系。A/B/C方案名称放在聊天说明和文件名中。

各组的封面、内容、复杂内容页保持组内一致。可以让三组呈现不同构图，但全部覆盖确认表要求的信息。展示时分别说明A的比赛风格来源，以及B、C与当前业务定位的关系。等待用户选择后再制作全稿。
